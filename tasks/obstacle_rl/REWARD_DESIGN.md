# RoSpider 걷기 강화학습 정리

RoSpider(다리 6개 + 팔, 3.2 kg)가 장애물을 넘도록 강화학습(RL)을 시키면서 **무엇을, 왜, 어떻게 했고, 결과가 어땠는지** 적는 문서.
실험할 때마다 맨 아래 "실험 기록"에 이어 쓴다. 직접 돌려서 본 숫자만 적고, 아직 확인 못 한 건 **(미확인)** 으로 표시한다.

## 1. 한 줄 요약

> 기존에 손으로 짠 걸음(tripod 걸음)보다 장애물을 더 잘 넘는 걸음을, 카메라 없이 몸 감각만으로 배우게 하는 게 목표다.
> 그냥 "빨리 가라"고만 가르쳤더니 걷지 않고 미끄러져 가는 꼼수를 배웠다. 그래서 지금은 "기존 걸음을 흉내 내면서 가라"고 가르치는 중이다.

## 2. 용어 (이것만 알면 읽을 수 있음)

| 용어 | 쉬운 뜻 |
|---|---|
| 강화학습 (RL) | 로봇이 시행착오로 배우는 방법. 잘하면 점수(보상)를 주고, 못하면 점수를 깎는다. 로봇은 점수를 많이 받는 쪽으로 행동을 바꾼다 |
| 정책 | 학습된 뇌. 지금 몸 상태를 보고 "다리를 어떻게 움직일지" 정한다 |
| 보상 | 잘했을 때 주는 점수. 무엇에 점수를 주느냐가 곧 "무엇을 가르치느냐"다 |
| 벌점 | 마이너스 보상. 하지 말았으면 하는 행동에 준다 |
| 가중치 | 각 보상이 얼마나 중요한지. 클수록 로봇이 더 신경 쓴다 |
| tripod 걸음 | 다리 6개를 3개씩 두 조로 나눠 번갈아 딛는 걸음. 곤충이 이렇게 걷는다. A조 = 왼앞(LF)·오른가운데(RM)·왼뒤(LR), B조 = 오른앞(RF)·왼가운데(LM)·오른뒤(RR) |
| 베이스라인 | 비교 기준. 여기서는 `rospider_wasd.py` 에 손으로 짜 둔 tripod 걸음 |
| 블라인드 | 카메라 / 지형 정보 없이 몸 감각(기울기, 관절 각도)만 보고 걷는 것. 실제 로봇에 지형 센서가 없어서 이렇게 한다 |
| iteration | 학습 1회. 2048마리가 동시에 0.5초씩 움직여 보고 정책을 한 번 고친다 |
| 박자 (gait clock) | 1.2 Hz(1초에 1.2번) 돌아가는 시계. "지금 어느 조가 발을 들 차례인지" 알려준다 |

## 3. 단계 계획

| 단계 | 할 일 | 넘어가는 기준 | 상태 |
|---|---|---|---|
| 0 | 걸음을 숫자로 재는 도구 만들기 + 베이스라인 측정 | 같은 조건에서 베이스라인 숫자 확보 | 끝 (11/7) |
| 1 | 평지에서 tripod 걸음 배우기 | 아래 "1단계 기준" 통과 + 영상 확인 | 진행 중 |
| 2 | 방지턱 8 cm, 구덩이 5 cm 넘기 (낮은 것부터 점점 높게) | 베이스라인보다 높은 통과율 | 예정 |
| 3 | 굴러가는 파이프, 그레이팅 계단, 실물 코스 맵 1·2 | 계단에서 막히면 카메라를 쓸지 다시 결정 | 예정 |
| 4 | 실제 로봇에 옮길 준비 (서보 반응 지연 재기, 게인 확인) | | 예정 |

**규칙: 단계가 끝나면 영상과 숫자를 보고 사람이 확인한 뒤에만 다음 단계로 간다.**

**1단계 기준**
- tripod 일치율 85 % 이상 (베이스라인 76.5 %)
- 걸음 속도 약 1.2 Hz (박자와 같음), 다리 6개 모두 실제로 딛기
- 15초 동안 방향이 5° 이내로만 틀어질 것 (베이스라인 17.7°)
- 발 미끄러짐이 베이스라인보다 작을 것
- 영상으로 봤을 때 베이스라인처럼 자연스럽게 걸을 것

## 4. 왜 이렇게 했나

**① 속도 점수만 주면 꼼수를 배운다**
실험 1에서 "명령한 속도로 앞으로 가면 점수"만 줬더니, 로봇이 다리 3개를 계속 들고 나머지 3개로 바닥을 밀며 미끄러져 갔다.
속도는 맞았으니 점수는 잘 받았지만 걷는 게 아니었다. 다리를 6개 다 쓰는 것보다 그게 쉬웠기 때문이다.

**② 그래서 "걸음 모양"에도 점수를 준다**
조사해 보니 다리 많은 로봇 연구들도 걸음 규칙을 따로 가르친다. 방법은 크게 세 가지다.
- 박자를 주고 박자에 맞게 발을 디디면 점수 ← **우리가 씀**
- 기존 걸음 동작을 따라 하면 점수 ← **우리가 씀**
- 다리마다 진동 신호기(CPG)를 달고 RL 이 그 신호를 조절 ← 위 방법이 안 되면 다음 후보

**③ 기존 걸음을 "베끼기만" 하지 않는 이유**
나중에 계단이나 파이프를 넘으려면 다리를 더 높이 드는 등 걸음을 바꿀 수 있어야 한다.
그래서 처음(평지)에는 기존 걸음을 강하게 따라 하게 하고, 장애물 단계에서는 따라 하기 점수를 줄여서 스스로 바꿀 여지를 준다.

**④ 블라인드인 이유와 한계**
실제 로봇에는 지형 센서가 없다. 그래서 정책은 몸 기울기, 회전 속도, 관절 각도만 본다.
학습할 때만 "채점하는 쪽(critic)"이 지형과 몸 속도를 보고 더 정확하게 채점해 준다. 실제 로봇에는 필요 없는 부분이다.
단, 앞을 못 보니까 계단에서 약하다고 알려져 있다. 3단계에서 카메라를 쓸지 다시 정한다.

## 5. 로봇이 보는 것 / 하는 것

**보는 것 (실제 로봇에서도 얻을 수 있는 값만)**
- 몸 기울기, 몸 회전 속도 (IMU)
- 다리 18개 관절의 각도와 속도 (서보)
- 받은 명령 (얼마나 빨리, 어느 방향으로)
- 바로 전에 낸 동작
- 박자 시계 (지금 어느 조가 발을 들 차례인지)

**하는 것**
- 다리 18개 관절의 목표 각도를 50번/초 정한다. 팔과 집게는 고정.

**학습 환경**
- 2048마리를 동시에 학습 (노트북 RTX 4060 기준, 1500회 학습에 약 40분)
- 실제 로봇과 차이가 나도 버티게, 매번 조금씩 바꿔 준다: 바닥 마찰 0.5 ~ 1.0, 몸무게 +0.8 ~ 1.8 kg, 가끔 살짝 밀기
- 넘어지면(몸통이 바닥에 닿거나 1 rad 넘게 기울면) 그 판은 끝

## 6. 보상 (점수표)

### 6-1. 기본 점수 (처음부터 있던 것)

| 무엇에 | 점수 | 쉬운 설명 |
|---|---|---|
| 명령 속도 맞추기 | +1.5 | 시킨 속도로 갈수록 점수 |
| 명령 방향(회전) 맞추기 | +0.5 → **+1.0** | 똑바로 가라는 명령을 잘 지킬수록 점수. 1단계에서 더 엄격하게 바꿈 (방향이 틀어지는 문제 때문) |
| 앞으로 나아가기 | +5.0 | 실제로 앞으로 간 만큼 점수 (시킨 속도까지만) |
| 발 오래 들기 | +0.2 | 발을 0.3초 이상 들었다 놓으면 점수 |
| 위아래로 출렁임 | 벌점 | 몸이 덜컹거리면 감점 |
| 몸 기울어짐 | 벌점 | 몸이 기울면 감점 |
| 힘 과하게 쓰기, 동작 급변 | 벌점 | 다리를 거칠게 쓰면 감점 |
| 허벅지가 바닥에 닿음 | 벌점 | 다리를 끌면 감점 |
| 관절 한계까지 꺾기 | 벌점 | 무리한 자세 감점 |

### 6-2. 1단계에서 새로 넣은 걸음 점수

| 무엇에 | 점수 | 쉬운 설명 |
|---|---|---|
| **기존 걸음 따라 하기** | +2.0 (가장 큼) | 박자에 맞춰 베이스라인 tripod 걸음과 관절 각도가 비슷할수록 점수. 걸음 모양을 잡는 핵심 |
| **박자대로 딛기** | +1.0 | A조가 들 차례에 A조가 떠 있고 B조가 딛고 있으면 점수 (그 반대도) |
| 발 높이 들기 | +0.5 | 들 차례인 발이 5 cm 까지 높이 뜰수록 점수. 발 끌기 방지 |
| 딛은 발 미끄러짐 | -0.5 | 땅에 닿은 발이 미끄러지면 감점. 이번 꼼수(미끄러져 가기) 방지 |

그 밖에 바꾼 것
- 다리를 움직일 수 있는 폭을 2배로 늘림. 기존 걸음은 허벅지를 크게(0.6 rad) 드는데 예전 폭으로는 그만큼 들기 어려웠다.
- 명령 속도를 0.08 ~ 0.20 m/s 로 올림. 기존 걸음 속도(0.18 m/s)를 포함하게.
- 다리 힘(게인)은 실제로 걷는 걸 확인한 `rospider_wasd.py` 값을 씀.

**(미확인)** 점수 크기는 출발값이다. 결과를 보고 조정한다.

## 7. 어떻게 평가하나 (`gait_eval.py`)

조건을 똑같이 맞추고 RL 정책과 베이스라인을 각각 15초 걷게 해서 잰다.
평지, 바닥 마찰 0.8, 몸무게 3.2 kg, 밀기 없음, 16마리 평균.

| 숫자 | 뜻 | 좋은 방향 |
|---|---|---|
| 전진 속도 | 1초에 몇 m 갔나 | 명령과 비슷 |
| 옆으로 샌 거리 | 똑바로 가야 하는데 옆으로 얼마나 벗어났나 | 작을수록 |
| 방향 틀어짐 | 15초 뒤 몸이 몇 도 돌아갔나 | 작을수록 |
| tripod 일치율 | 시간 중 "한 조 3발은 딛고, 다른 조 3발은 뜬" 비율 | 클수록 |
| 걸음 수 | 다리 하나가 1초에 몇 번 딛나 | 약 1.2 |
| 발 높이 | 들 때 발이 얼마나 높이 뜨나 | 적당히 (베이스라인 7 cm) |
| 미끄러짐 | 땅에 닿은 발이 얼마나 미끄러지나 | 작을수록 |
| `gait.png` | 발이 언제 닿았는지 그린 그림. 검은색 = 땅에 닿음. tripod 면 위 3줄과 아래 3줄이 번갈아 검다 | |
| `walk.mp4` | 걷는 영상 | 눈으로 확인 |
